Web UI not included

This plakar was built without its web UI

The web UI is only built into tagged releases. A binary built from the main branch does not include it: go build or make in a clone, or go install github.com/PlakarKorp/plakar@main.

The plakar API is running; only the UI is missing. To get it:

  1. Install a release go install github.com/PlakarKorp/plakar@latest
  2. Or download a prebuilt binary plakar.io/download
  3. Or build the UI from source before building plakar make ui plakar

Building the UI from source requires Node.js and pnpm.
